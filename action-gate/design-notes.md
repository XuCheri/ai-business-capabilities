# 演示界面设计

使用 frontend-design skill。主题是 AI 工具执行前的业务审批，核心任务是让操作人看清「提议、权限、审批、一次性许可」的边界。

- 配色：纸白 `#f7f9fb`、执行台深蓝 `#233b62`、通行青 `#31786e`、审核金 `#a97924`、拒绝红 `#ad514e`、冷线灰 `#d8e1eb`。
- 字体：中文使用系统无衬线，标题采用偏窄且粗的 Arial / 系统黑体；仅 JSON 编辑器采用等宽字体。所有状态都有文字，不依赖颜色。
- 布局：左侧深蓝工具清单，中间白底调用草稿，右侧审批票据；下方连贯审计流水。审批票据用折角、虚线与可消费的印章式状态作唯一视觉记忆点，其他部分低装饰。
- 交互：预检 → 审批 → 消费为真实顺序，清楚展示许可绑定对象；用真实触发的状态反馈，不做自动动画。敏感参数预览隐藏，原始草稿仅留在输入区。

草图：

```text
工具目录 │ 待检查调用草稿          │ 审批票据
读取     │ 主体 / 可信租户          │ 决策 / 到期 / 绑定字段
外发     │ JSON参数编辑             │ 审批身份切换
批量写   │ 预检 / 改参 / 试执行      │ 批准 / 拒绝 / 消费
未知     ├─────────────────────────┴──────────
         │ 可导出的脱敏审计流水
```

审阅后删除了通用大数字卡片、英文大写眉题与渐变装饰，以审批票据和业务状态作为页面主视觉。手机端工具清单变成横向按钮，三栏顺序堆叠。
